
## Dataset Source

This project uses the **High Volume For-Hire Vehicle (HVFHV)** trip dataset provided by the New York City Taxi and Limousine Commission (TLC).

**Official Dataset Source:**  
https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

---

## Dataset Description

The dataset contains trip-level information for **High Volume For-Hire Vehicles (HVFHV)** operating in New York City, including ride activity from services such as app-based transportation platforms.

The data includes operational and trip-related details such as:

- Pickup and drop-off timestamps  
- Pickup and drop-off location IDs  
- Trip miles and duration  
- Fare and revenue-related metrics  
- Shared ride indicators  
- Dispatching base numbers  
- Ride demand trends across service zones

---

## Time Period Used

This analysis was conducted using **January, February, and March 2026 HVFHV trip datasets** to evaluate ride demand, trip distribution, operational trends, and revenue-related patterns across New York City.

## Project Objective

The objective of this project is to analyze **New York City HVFHV ride activity** and generate actionable insights related to:

- Peak demand periods  
- Trip volume trends  
- Geographic ride distribution  
- Revenue performance  
- Operational efficiency
